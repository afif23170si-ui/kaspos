# Login & Akses Keamanan

Keamanan data toko Anda dimulai dari sini. Sistem KasPOS menggunakan sistem otentikasi aman untuk memastikan hanya karyawan berwenang yang bisa mengakses data.

## 1. Masuk ke Sistem (Login)

1.  Akses alamat website KasPOS yang diberikan oleh tim IT/Pemilik.
2.  Masukkan **Email** dan **Password** yang telah didaftarkan.
3.  Klik **Sign In**.
4.  Jika komputer ini digunakan bersama (kasir umum), **JANGAN** centang "Remember Me" agar akun otomatis logout saat browser ditutup.

## 2. Hak Akses (Roles)

Setiap pengguna memiliki tampilan menu yang berbeda tergantung lingkup kerjanya. KasPOS membagi akses menjadi 7 tipe pengguna:

### Manajemen & Admin
*   **Super Admin**: Pemilik sistem. Memiliki akses mutlak termasuk **Reset Data**, **Ubah Pengaturan Toko**, dan Manajemen User.
*   **Manager**: Bertanggung jawab atas operasional toko. Bisa melihat **Dashboard**, **Laporan Penjualan**, mengelola **Produk**, dan **Pelanggan**. 
*   **Accounting**: Fokus pada keuangan. Akses menu **Laporan Laba Rugi**, **Arus Kas (Cash Flow)**, dan Input **Pengeluaran (Expenses)**.
*   **Inventory**: Fokus pada gudang. Mengelola **Stok**, **Bahan Baku**, **Supplier**, dan **Stock Opname**.

### Operasional
*   **Kasir**: Fokus melayani pembayaran. Hanya bisa akses halaman **POS** dan **Riwayat Transaksi** (terbatas shiftnya).
*   **Kitchen**: Peran khusus untuk layar di dapur. Hanya menampilkan pesanan masuk.
*   **Waiter**: Peran untuk pelayan yang keliling mencatat pesanan via tablet/HP. Hanya bisa input order, tidak bisa bayar/checkout.

## 3. Lupa Password?

Jika Anda lupa kata sandi:

1.  Klik tulisan **Forgot Password?** di halaman login.
2.  Masukkan alamat email Anda.
3.  Sistem akan mengirimkan Link Reset ke email tersebut.
4.  Buka email, klik tombol **Reset Password**.
5.  Buat password baru.

## 4. Mengganti Password & Profil

Saat sudah login, Anda bisa mengubah data diri sendiri:

1.  Klik Nama/Foto Profil Anda di pojok kanan atas Dashboard.
2.  Pilih **Profile**.
3.  Di sini Anda bisa mengganti:
    *   Foto Profil.
    *   Nama Lengkap.
    *   Password Lama ke Password Baru.
